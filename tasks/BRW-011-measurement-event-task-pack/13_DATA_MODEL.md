# BRW-011 Suggested Data Model

Identity: measurement_event_id / battery_id / experiment_id

Ultrasound: asset / frame / event_order / waveform locator

Time+sync: provisional timestamp / elapsed / match status / sync error / candidate count / ambiguity / boundary / validated_sync / anchor

Electrical: asset / locator / timestamp / cycle / step / voltage / current / capacity / temperature / etc.

Quality: event_quality_status / analysis_eligible / reason
